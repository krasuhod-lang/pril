# SEO Dashboard для CEO

Интерактивный одностраничный дашборд для презентации генеральному директору. Главный фокус — **НК (Новые Клиенты)** и их связь с органическим трафиком из поисковых систем.

## Запуск

Дашборд — это статичный сайт без сборки. Достаточно открыть `index.html` через любой локальный HTTP-сервер:

```bash
python3 -m http.server 8000
# затем откройте http://localhost:8000
```

> Открытие `index.html` напрямую через `file://` тоже работает, но в этом случае браузер не сможет автоматически подхватить эталонный `datank.xlsx` — просто перетащите файл в зону загрузки.

## Возможности

* **Drag-and-drop загрузка** `.xlsx` / `.csv` (SheetJS).
* **State management:** загруженные данные и выбранные фильтры сохраняются в `localStorage` — при обновлении страницы ничего не сбрасывается.
* **ETL:** удаление пустых строк (без `Месяц`), приведение чисел к числовому формату, замена `,` → `.`, преобразование процентов в долю.
* **Фильтры:** Месяц, Источник трафика, Страница/продукт.
* **KPI-карточки** с дельтой к прошлому месяцу: НК, Визиты, CR, AR.
* **4 графика:**
  1. Воронка `Показы → Визиты → Заявки → НК`.
  2. Динамика НК по источникам (Яндекс / Google / Organic).
  3. Корреляция «Визиты vs НК» (combo: столбцы + линия).
  4. Эффективность продуктов / кластеров (горизонтальный бар: НК + AR).
* **Таблица детализации** с сортировкой (по умолчанию `НК онлайн ↓`) и экспортом обратно в `.xlsx`.
* **Автоматические инсайты:** визиты на 1 НК по источникам, лучший по AR кластер, MoM-рост НК.

## Поддерживаемые форматы данных

Дашборд понимает **две формы** входных файлов:

### A) «Спецификационная» форма (рекомендуемая)

Каждая строка — комбинация (месяц × источник × страница × кластер) со столбцами:

`Месяц`, `Источник трафика`, `Страница/продукт`, `Название рекламной кампании`,
`Показы`, `Клики`, `CTR`, `Визиты`,
`Заявки онлайн-выдача`, `Заявки офлайн-выдача`, `CR онлайн`, `CR офлайн`,
`НК онлайн`, `НК офлайн`, `AR онлайн`, `AR офлайн`.

### B) Агрегатная форма (как в `datank.xlsx`)

Одна строка на месяц с полями `SEO-трафик всего`, `Визиты на продуковые страницы`, `Заявки всего`, `Договоры всего`, `Новые клиенты (договор)` и сегментами `Прогретые / Присматриваются / Сыкуны`. Дашборд автоматически разворачивает такие строки на 3 «продукта»-сегмента, чтобы все графики и фильтры работали единообразно. Источник в этом случае — `Organic` (файл не разделяет Яндекс и Google).

## Файлы

```
index.html   — разметка и подключение CDN-зависимостей
styles.css   — оформление
app.js       — ETL, состояние, фильтры, KPI, графики, инсайты, грид, экспорт
datank.xlsx  — эталонный набор данных (загружается по умолчанию)
```

## Зависимости (через CDN)

* [SheetJS](https://sheetjs.com/) `xlsx@0.18.5` — чтение/запись Excel.
* [Chart.js](https://www.chartjs.org/) `4.4.1` — все графики.
